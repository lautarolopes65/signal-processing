# Instroducción al Procesamiento de Señales

El trabajo utiliza **GNU Octave** para el análisis e implementación de sistemas discretos y procesamiento de señales.

## Contenidos

- Análisis de señales discretas y TFTD.
- Respuesta impulsional y respuesta en frecuencia.
- Sistemas lineales e invariantes en el tiempo.
- Implementación de sistemas mediante ecuaciones en diferencias.
- Filtros FIR.
- Modelado de canales digitales con ecos.
- Procesamiento y ecualización de señales de audio.

## Herramientas

- GNU Octave
- Scripts `.m`
- Procesamiento de señales y audio
